# Quick Task Plan: 260907-d8a

Allow configuring display repetitions in configuration (defaulting to 2), and automatically reduce repetitions to 1 if more than 1 message is sent per minute to Awtrix.

## Planned Tasks

1. **Configuration & Validation**:
   - Add `repeat: 2` to `defaultConfig` in `src/config/defaults.js`.
   - Support `DISPLAY_REPEAT`, `REPEAT`, and `NOTIFICATION_REPEAT` env variables in `src/config/index.js`.
   - Support `repeat` and `displayRepeat` in JSON config.
   - Validate `repeat` in `validateConfig` (must be non-negative integer).
   - Update `config/flightscanner.json.example` and `config/default-flightscanner.example`.

2. **Payload Formatter Default**:
   - Update default `repeat` from 3 to 2 in `formatNotificationPayload` in `src/services/notification/formatter.js`.

3. **Dynamic Rate Limiting in MQTT Publisher**:
   - In `src/services/notification/mqtt.js`:
     - Track message publish timestamps over a sliding 60-second window.
     - When publishing, if more than 1 message is sent within 60 seconds (i.e. at least 1 message sent in the past minute), reduce `repeat` to 1.
     - Support custom `now` function and `rateLimitWindowMs` in options for testing.

4. **Testing & Verification**:
   - Unit tests in `test/config.test.js` for default, JSON, env variable, and validation of `repeat`.
   - Unit tests in `test/formatter.test.js` for default repeat of 2 and custom repeat option.
   - Unit tests in `test/mqtt.test.js` for normal configured repeat (2) and reduced repeat (1) when rate > 1 message/min.
   - Verify all tests pass with `npm test`.
