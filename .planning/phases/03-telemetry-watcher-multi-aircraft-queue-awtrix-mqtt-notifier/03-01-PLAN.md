  <files>src/services/tracking/queue.js</files>
  <read_first>flightscanner.js</read_first>
  <action>
    Create `src/services/tracking/queue.js`:
    - Implement `FlightQueue` class:
      - Constructor accepts `{ cooldownMs, processCallback, delayBetweenFlightsMs = 15000 }`.
      - Maintains:
        - `activeCooldowns`: Map of `flightKey` -> `timestamp` to prevent duplicate alerts within `cooldownMs` (default 30 mins).
        - `queue`: Array of queued aircraft telemetry.
        - `isProcessing`: Boolean processing lock.
      - Methods:
        - `enqueue(aircraft)`: Checks cooldown for `aircraft.flight || aircraft.r || aircraft.hex`. If not on cooldown and not already queued, adds to queue and triggers `processNext()`.
        - `isOnCooldown(key)`: Returns boolean whether key is currently in cooldown window.
        - `setCooldown(key)`: Records cooldown timestamp.
        - `processNext()`: Asynchronously processes items sequentially with spacing to prevent overlapping notifications.
        - `clear()`: Clears queue and cooldowns.
  </action>
  <verify>node -e 'const { FlightQueue } = require("./src/services/tracking/queue"); console.log("FlightQueue loaded");</verify>
  <done>src/services/tracking/queue.js exports FlightQueue</done>
</task>
