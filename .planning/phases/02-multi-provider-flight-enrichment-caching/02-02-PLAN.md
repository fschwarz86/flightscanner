    - Implement class `FlightCache`:
      - Constructor takes `defaultTtlMs` (default 4 hours = 14,400,000 ms) and optional max size limit.
      - `get(key)`: Returns cached value if valid, or `null` if missing or expired.
      - `set(key, value, ttlMs)`: Stores key-value with expiration timestamp.
      - `has(key)`: Returns boolean indicating if non-expired entry exists.
      - `delete(key)`: Removes entry.
      - `clear()`: Clears all entries.
      - `prune()`: Iterates and removes all expired entries.
      - `size()`: Returns number of non-expired entries.
  </action>
